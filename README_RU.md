# TrimUI Companion Pro — Windows build

Современный неофициальный GUI-компаньон для TrimUI Smart Pro. Приложение не связано с производителем TrimUI.

## Что входит
- Тёмный интерфейс с боковой навигацией и обзорной панелью.
- Сканирование ROM-библиотеки на microSD, поиск, размер и платформы.
- Поиск полных дубликатов SHA-256 без автоматического удаления.
- Экспорт каталога в CSV.
- Резервное копирование выбранных папок.
- Копирование обложек и тем в настраиваемые каталоги.
- Проверка SSH и передача файла/папки через SCP.
- Настраиваемые пути для сторонних прошивок.

## Для пользователя Windows
Готовый exe создаётся Windows-сборкой через GitHub Actions. Это нужно, потому что PyInstaller не умеет собирать Windows EXE из Linux-среды.

1. Загрузить содержимое папки проекта в новый GitHub-репозиторий.
2. Открыть вкладку **Actions** и разрешить запуск workflows, если GitHub попросит.
3. Запустить workflow **Build Windows EXE** (или отправить push в main).
4. В завершившемся запуске скачать artifact `TrimUICompanion-Windows`.
5. Распаковать архив и запустить `TrimUICompanion.exe`.

Workflow использует Windows runner, устанавливает зависимости и собирает однофайловый EXE с PyInstaller. Никакой Python на конечном ПК не нужен.

## Локальная сборка
Нужен Python 3.10+:
- `build_exe.bat` — ставит зависимости и создаёт `dist\TrimUICompanion.exe`.
- `run.bat` — запуск из исходников.

## Безопасность и ограничения
- Программа не форматирует карту, не обновляет прошивку и не удаляет игры.
- Пути Saves/States, обложек и тем отличаются по прошивкам. Уточни их для своей сборки.
- Сетевой режим требует включённого SSH на консоли и Windows OpenSSH Client. Пароль программа не хранит.
- Перед копированием тем или сетевой передачей проверь путь назначения.
- Сначала тестируй на резервной копии microSD.
